# MAX Image Reader Bot

Бот распознаёт текст на каждом изображении через локальный PaddleOCR. Если в сообщении или на изображении найден идентификатор `bx…`, `ii…` или `us…`, бот прикладывает один QR-код к полному распознанному тексту.

## Запуск в Windows

1. Установите Node.js LTS: https://nodejs.org/
2. Установите Python 3.12 x64. PaddlePaddle пока не поддерживает текущий Python 3.14 из этой среды.
3. В этой папке создайте `.env` по образцу `.env.example`.
4. Скопируйте токен из `token.txt` в значение `BOT_TOKEN` и удалите `token.txt` после этого.
5. Установите Node-зависимости:

6. Установите PaddleOCR:

```powershell
npm run ocr:install
```

7. Запустите бота:

```powershell
npm start
```

Для остановки нажмите `Ctrl+C`.

## HTTPS-соединение с MAX

`npm start` запускает бота через `start.mjs`, который добавляет официальный `Russian Trusted Root CA` из `russian-trusted-root-ca.pem` в доверенные CA Node.js. Проверка TLS-сертификатов остаётся включённой. Чтобы использовать другой CA-файл, задайте `NODE_EXTRA_CA_CERTS` в окружении до запуска.

## Что умеет текущая версия

- `/start`, `/help` — краткая инструкция;
- `/read` — запросить изображение и распознать весь текст;
- `/qr <код>` — создать QR-код;
- `/barcode <код>` — создать один штрихкод Code128 вместо QR;
- `/code <код>` — псевдоним команды `/qr`;
- отправленный текстовый идентификатор `bx…`, `ii…` или `us…` автоматически создаёт QR-код;
- каждое изображение в сообщении распознаётся отдельно; найденный на фото идентификатор добавляет QR-код к распознанному тексту, иначе возвращается только текст.

После установки Node.js и Python 3.12 зависимости устанавливаются командами `npm install` и `npm run ocr:install`. Запуск: `npm start`.
