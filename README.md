# MAX Barcode Bot

Бот распознаёт текст на скриншотах и возвращает его в чат без генерации кодов из изображения. В текстовых сообщениях идентификаторы `cl`, `us`, `bx`, `ii` и `%301%` автоматически создают QR-коды. Также доступны `/qr <текст>` и `/barcode <текст>`.

## Запуск

1. Установите Node.js 20 или новее.
2. Создайте `.env` по образцу `.env.example` и укажите `BOT_TOKEN`.
3. Установите зависимости командой `npm install`.
4. Запустите бота командой `npm start`.

Отправьте изображение напрямую или вызовите `/read`, чтобы получить распознанный текст. Модели Tesseract для русского и английского скачиваются при первом распознавании и кэшируются. Code128 принимает ASCII-текст длиной до 180 символов; QR по умолчанию создаётся только для ключей из текстовых сообщений.

`npm start` использует `start.mjs`, который добавляет официальный корневой сертификат MAX из `russian-trusted-root-ca.pem` в доверенные CA Node.js. Проверка TLS-сертификатов остаётся включённой. Другой CA-файл можно задать через `NODE_EXTRA_CA_CERTS`.
