# MAX Barcode Bot

Бот распознаёт текст на скриншотах и автоматически создаёт QR-код, если в сообщении или на изображении найден идентификатор `bx…`, `cl…`, `ii…`, `us…` или `%301%…`. В QR-код и подпись передаётся полный текст сообщения, исходное сообщение с идентификатором удаляется. Обычные сообщения без подходящего идентификатора игнорируются.

## Запуск

1. Установите Node.js 20 или новее.
2. Создайте `.env` по образцу `.env.example` и укажите `BOT_TOKEN`.
3. Установите зависимости командой `npm install`.
4. Запустите бота командой `npm start`.

Отправьте изображение с кодом или вызовите `/read`, чтобы получить распознанный текст без генерации кода. Модели Tesseract для русского и английского скачиваются при первом распознавании и кэшируются. Команды `/qr <текст>` и `/barcode <текст>` создают QR-код или Code128 из всего переданного текста и показывают его в подписи.

`npm start` использует `start.mjs`, который добавляет официальный корневой сертификат MAX из `russian-trusted-root-ca.pem` в доверенные CA Node.js. Проверка TLS-сертификатов остаётся включённой. Другой CA-файл можно задать через `NODE_EXTRA_CA_CERTS`.
