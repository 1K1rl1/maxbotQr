# MAX Barcode Bot

Бот распознаёт текст на скриншотах и автоматически создаёт штрихкоды Code128, если в сообщении или на изображении найден идентификатор `bx…`, `cl…`, `ii…`, `us…` или `%301%…`. Полный текст добавляется в подпись к изображению, исходное сообщение удаляется. Обычные сообщения без подходящего идентификатора игнорируются.

## Запуск

1. Установите Node.js 20 или новее.
2. Создайте `.env` по образцу `.env.example` и укажите `BOT_TOKEN`.
3. Установите зависимости командой `npm install`.
4. Запустите бота командой `npm start`.

Отправьте изображение с кодом или вызовите `/read`, чтобы получить распознанный текст без генерации штрихкода. Модели Tesseract для русского и английского скачиваются при первом распознавании и кэшируются. Code128 создаётся для найденного ASCII-кода, а полный текст сообщения служит подписью. Команды `/qr <текст>` и `/barcode <текст>` остаются доступны.

`npm start` использует `start.mjs`, который добавляет официальный корневой сертификат MAX из `russian-trusted-root-ca.pem` в доверенные CA Node.js. Проверка TLS-сертификатов остаётся включённой. Другой CA-файл можно задать через `NODE_EXTRA_CA_CERTS`.
