# MAX Barcode Bot

Бот создаёт штрихкоды Code128 из переданного текста.

## Запуск

1. Установите Node.js 20 или новее.
2. Создайте `.env` по образцу `.env.example` и укажите `BOT_TOKEN`.
3. Установите зависимости командой `npm install`.
4. Запустите бота командой `npm start`.

Команда бота: `/barcode <текст>`. Code128 принимает ASCII-текст длиной до 180 символов.

`npm start` использует `start.mjs`, который добавляет официальный корневой сертификат MAX из `russian-trusted-root-ca.pem` в доверенные CA Node.js. Проверка TLS-сертификатов остаётся включённой. Другой CA-файл можно задать через `NODE_EXTRA_CA_CERTS`.
