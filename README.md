# MAX Barcode Bot

Бот читает текст со скриншотов на русском и английском языках. Для найденных идентификаторов `cl`, `us`, `bx`, `ii` и `%301%` он автоматически прикладывает QR-коды. Также доступны команды `/qr <текст>` и `/barcode <текст>`.

## Запуск

1. Установите Node.js 20 или новее.
2. Создайте `.env` по образцу `.env.example` и укажите `BOT_TOKEN`.
3. Установите зависимости командой `npm install`.
4. Запустите бота командой `npm start`.

Для распознавания скриншота отправьте изображение боту или вызовите `/read`. Бот вернёт распознанный текст; найденные ключи будут закодированы в QR. Модели Tesseract для русского и английского загружаются при первом распознавании и кэшируются.

Code128 принимает ASCII-текст длиной до 180 символов. QR-код используется по умолчанию для распознанных ключей.

`npm start` использует `start.mjs`, который добавляет официальный корневой сертификат MAX из `russian-trusted-root-ca.pem` в доверенные CA Node.js. Проверка TLS-сертификатов остаётся включённой. Другой CA-файл можно задать через `NODE_EXTRA_CA_CERTS`.
